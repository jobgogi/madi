# デザイン要求事項

### トーン&原則
* カード基盤、ミニマルスタイル
* モバイル、タブレット、デスクトップ基準にデザイン
* severity(critical/warning/info)는 색상 + 텍스트 라벨 함께 표시 (색상만으로 구분 금지)
* 모든 비동기 작업(분석 중, 저장 중 등)에 로딩 상태 표시
* 접근성: 인터랙티브 요소에 aria-label 부여
* ダークモード適用しないこと

## 화면별 디자인 요구사항
### 대시보드 (홈)
* 상단: 서비스명 + "새 학습" 버튼
* 일별 학습 잔디 그래프: GitHub 컨트리뷰션 그래프 스타일, 최근 365일 전체(약 53주×7행, 가로 스크롤 허용), 학습량에 따라 색 진하기 단계(5단계: 없음~많음) 표시, 범례 포함
* 자주 틀리는 카테고리: 표/막대 형태가 아닌 메트릭 카드 그리드(자동 줄바꿈), 카테고리명 + 건수, 클릭 시 해당 카테고리 필터링된 리스트로 이동
* 방향 필터: 전체 / 日→韓 / 韓→日 (탭 또는 토글 버튼)
* 하단: "전체 기록 보기" 링크 → 리포트 리스트 화면

### 입력 화면
* 원문 입력창 + 번역 입력창 (세로 배치)
* 글자 수 카운터
* 방향 전환 토글 (日→韓 / 韓→日)
* 긴 글 입력 시 "문장 수만큼 API 요청이 발생합니다" 안내 문구
* "분석 시작" 버튼

### 리포트 화면 (핵심 화면)
* 전체 원문 표시
* 내 번역 vs AI 번역(기준) — 문제 구간을 색상으로 대조 표시 (내 번역: 빨간 계열 강조, AI 번역: 초록 계열 강조)
* 가장 잘한 점: 초록 배경 배너, 별 아이콘
* 아쉬운 점: 빨간 배경 배너, critical 건수 뱃지, 경고 아이콘
* 이전 대비 나아진 점: 강조 테두리 카드, 성장 아이콘(트렌드업)
* 총평 텍스트
* 난이도 뱃지: ja_to_ko는 JLPT(N5~N1), ko_to_ja는 TOPIK(1~6급) — 뱃지 라벨이 방향에 따라 달라짐
* 하단 버튼: "목록으로" (또는 저장 후 액션)

### 설정 화면
* LLM 제공자 선택 (드롭다운): OpenAI / Claude / Ollama
* 선택에 따라 하단 필드 동적 전환 (API 키 입력 vs Ollama 엔드포인트 입력)
* Ollama 선택 시 Tailscale + OLLAMA_ORIGINS 안내 박스
에러 상태
카테고리별(API 키/네트워크/Ollama/저장 실패) 안내 문구 표시
저장 실패 시에도 분석 결과 화면 데이터는 유지, 재시도 버튼 제공
### 컬러/뱃지 규칙
|요소|색상 방향|
|----|----|
|critical|위험/경고 색 (빨강 계열)|
|warning|보통 강조 색 (주황/노랑 계열)|
|info|톤 다운된 무채색|
|JLPT/TOPIK 뱃지|강조 색(accent) 배경의 작은 필(pill) 뱃지|
|잔디 그래프|teal 계열 5단계 명도|
